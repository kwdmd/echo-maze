# ECHO MAZE

카메라의 손 동작과 마이크의 박수 소리로 조작하는 1인칭 미로 게임입니다.
HTML, CSS, JavaScript와 Canvas 레이캐스팅으로 구현했습니다.

## 실행

Node.js 18 이상이 설치된 환경에서 이 폴더를 터미널로 열고 실행하세요.

```sh
npm start
```

브라우저에서 `http://localhost:8080`을 엽니다. 별도 npm 패키지 설치나 빌드가 필요하지 않습니다.
파일을 더블클릭하는 대신 로컬 서버 또는 HTTPS 호스팅으로 실행하세요.
카메라·마이크 사용에는 브라우저 권한 허용이 필요합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 미로 탐험 시작 | 시작점에서 자동 이동 시작 |
| 장치 연결 | 카메라 손 인식 및 마이크 연결 |
| 갈림길에서 손을 위·아래·왼쪽·오른쪽으로 이동 | 가능한 방향 선택 |
| 손을 쥐었다 펴기 | 선택한 방향으로 이동 확정 |
| 박수 또는 M 키 | 전체 지도 열기·닫기 |
| 방향키 + Enter | 장치 없이 방향 선택·이동 |
| 화면의 방향 버튼 클릭 | 해당 방향으로 이동 |
| 다시 시작 | 탐험 기록을 초기화하고 시작점으로 복귀 |

고개 움직임과 마우스 드래그에 의한 시점 조작은 제거된 버전입니다.
화면은 이동 방향에 따라서만 자동으로 회전합니다.

## 게임 규칙

- 갈림길 사이에서는 자동으로 이동하며, 모퉁이에서도 길을 따라갑니다.
- 첫 갈림길에서만 뒤로 가기 선택지를 숨깁니다.
- 오른쪽 아래 미니맵에는 방문한 길만 표시됩니다.
- 전체 지도는 방문하지 않은 길까지 보여줍니다.
- 막다른 길에서는 방해꾼과 조우합니다. 미니게임은 미구현이며 현재는 자동 승리 후 돌아갑니다.
- `game.js`의 `resolveEncounter(won)`에 향후 미니게임 결과를 연결할 수 있습니다. `false`는 시작점 복귀입니다.
- 포탈에 도달하면 탈출 성공 후 시작점으로 돌아가며 탐험 기록이 초기화됩니다.

## GitHub 업로드

이 폴더의 **내용물**을 저장소 최상위에 올리세요. ZIP 파일 자체를 저장소에 올리는 대신 압축을 풀어 소스를 올립니다.
기존 Sites 배포용 `.git` 이력, `.openai` 설정, 인증 정보는 이 폴더에 포함하지 않았습니다.

Git으로 업로드할 경우 GitHub에 빈 저장소를 만든 뒤 아래 명령을 실행합니다.
`YOUR_USERNAME`과 `YOUR_REPOSITORY`를 실제 계정 및 저장소 이름으로 바꾸세요.

```sh
git init
git add .
git commit -m "Add ECHO MAZE game"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

GitHub 로그인은 사용 중인 Git 인증 도구의 안내를 따릅니다.
정적 호스팅 시 `index.html`, `style.css`, `game.js`를 같은 경로에 배치하면 됩니다.

## 검사

```sh
npm run check
npm test
```

검사는 첫 갈림길의 뒤로 가기 제한, 미로 경로, 방해꾼 승패 분기, 포탈 및 초기화, 지도 토글을 확인합니다.
실제 카메라·마이크 및 화면의 시각적 품질을 검증하는 테스트는 아닙니다.

## 외부 리소스와 현재 한계

- 손 인식: MediaPipe Tasks Vision 0.10.21을 jsDelivr에서 로드하고 Google Storage의 손 인식 모델을 사용합니다.
- 글꼴: Google Fonts의 Noto Sans KR을 사용합니다.
- 따라서 장치 인식을 처음 연결할 때 인터넷 연결이 필요합니다.
- 애플리케이션은 카메라 영상과 음성을 서버에 업로드하거나 저장하지 않고 브라우저에서 처리합니다.
- 박수는 소리 크기와 순간적인 변화를 이용해 감지하므로 다른 큰 소리에도 반응할 수 있습니다. 화면에서 감도를 조절할 수 있습니다.
- 실제 장치의 조명·촬영 각도·소음에 따라 손짓과 박수 인식 품질이 달라질 수 있으며 실제 장치 테스트가 필요합니다.
- 미니게임은 추후 구현 예정입니다.

별도의 오픈소스 라이선스는 지정하지 않았습니다. 공개 배포와 재사용 허용 범위가 정해지면 적절한 LICENSE 파일을 추가하세요.
